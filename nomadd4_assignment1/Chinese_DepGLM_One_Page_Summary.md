# Assignment 1: Chinese DepGLM Dataset Replacement and Phase 2 Sampling

For Assignment 1, we replaced the original Chinese dataset in NOMADD-4 with data from DepGLM (`DW/train.csv`). The original dataset contained **8,052 posts**, including 5,617 normal and 2,435 depressed posts. We converted the original labels into two categories: normal (label 0) and depressed (labels 1, 2, and 3). The script also identified 1,086 posts that contained multiple lines of text.

During data preparation, we removed 16 duplicate posts, cleaned the HTML and whitespace, and removed another 138 posts during ethics screening (122 unusable and 16 spam). The ethics screening was done using regex dry-run mode rather than a live API. After cleaning and filtering, **7,898 posts remained**, with 5,468 normal and 2,430 depressed. Since there weren't enough depressed posts to reach the original target of 5,000, we created a balanced Phase 1 dataset of **4,860 posts (2,430 per class)** using seed 42.

For Phase 2, we checked the existing `create_phase2_audit.py` script, but it requires model predictions to select posts using the original 45/45/10 sampling method. Since we don't have predictions for the new DepGLM dataset, we couldn't use that approach. After discussing it with the team, we decided to randomly select **250 posts, with 125 depressed and 125 normal**, using `random.Random(42)`. We sampled each class separately and then shuffled the selected posts.

We verified that all 250 selected posts had unique IDs, no duplicate text, valid labels, and an equal number from each class. The results were saved in `Chinese HE.xlsx` and `chinese_depglm_phase2_seed42.json`, following the existing Phase 2 format. The selected post IDs were also saved in `ablation/sampled_ids.json` for Assignment 2. Since we used random sampling instead of the original 45/45/10 method, the new Phase 2 dataset cannot be directly compared to the original sample when analyzing model failure categories.
