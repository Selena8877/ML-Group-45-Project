
# Model Comparison and Error Analysis

## Overview

This analysis compares the naive benchmark and K-Nearest Neighbours (KNN) baseline across four languages: Arabic, Chinese, Brazilian Portuguese, and Thai.

Both original and keyword-masked KNN datasets are evaluated to examine the impact of keyword masking on classification performance.

The analysis uses existing model predictions and evaluation metrics. No model retraining is required.

## Implementation

Three Python scripts were developed:

### 1. Model Comparison

File: `src/model_comparison.py`

Compares the naive benchmark and KNN models using accuracy, precision, recall, and F1-score for all four languages.

Output:
- `results/model_comparison.csv`

### 2. Error Analysis

File: `src/error_analysis.py`

Calculates true positives (TP), true negatives (TN), false positives (FP), and false negatives (FN).

It also compares KNN prediction correctness before and after keyword masking.

Outputs:
- `results/error_summary.csv`
- `results/misclassified_predictions.csv`
- `results/masking_comparison.csv`
- `results/masking_summary.csv`

### 3. Error Examples

File: `src/error_examples.py`

Matches misclassified prediction IDs to their original text in the processed test datasets.

Output:
- `results/error_examples.csv`

## How to Run

From the repository root, install the project dependencies:

```bash
python -m pip install -r requirements.txt
```

Then execute:

```bash
python src/model_comparison.py
python src/error_analysis.py
python src/error_examples.py
```

Run the scripts in this order because each stage uses results generated by the previous stage.

## Key Results

The original KNN test-set F1-scores were:

| Language | Naive F1 | KNN F1 |
|---|---|---|
| Arabic | 0.667 | 0.857 |
| Chinese | 0.000 | 0.807 |
| Portuguese | 0.000 | 0.438 |
| Thai | 0.000 | 0.214 |

KNN outperformed the naive benchmark across all four languages.

### Error Analysis

The original KNN models produced:

| Language | False Positives | False Negatives |
|---|---|---|
| Arabic | 14 | 2 |
| Chinese | 15 | 6 |
| Portuguese | 7 | 34 |
| Thai | 0 | 44 |

Portuguese and Thai had the highest numbers of false negatives, indicating difficulty identifying at risk posts.

The training datasets for these languages contained approximately 13% at risk examples, compared with approximately 50% for Arabic and Chinese. This imbalance may contribute to the observed differences.

### Keyword Masking

Comparing original and masked KNN predictions:

- Arabic: 1 previously correct prediction became incorrect.
- Chinese: 4 previously incorrect predictions became correct.
- Portuguese: 1 previously incorrect prediction became correct.
- Thai: No changes in prediction correctness.

Keyword masking had a limited and inconsistent impact on test-set accuracy.

## Limitations

- The language datasets differ in their class distributions.
- Arabic and Chinese identify depression risk, while Portuguese and Thai identify suicidal thoughts.
- The test sets contain 100 posts per language, limiting the precision of performance estimates.
- The analysis uses existing predictions and does not establish causal explanations for model errors.
- The observed results may not generalize to real-world class distributions.

## Future Improvements

Future work should investigate methods to improve recall for at risk posts, particularly in Portuguese and Thai.

Potential approaches include resampling, alternative text representations, and comparing additional classification models.

Model selection should consider precision, recall, and F1-score rather than relying on accuracy alone.
